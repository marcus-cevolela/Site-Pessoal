## 🎓 Sobre o projeto

### 🇧🇷 Português

O **Site Pessoal** é um projeto desenvolvido como **trabalho acadêmico para a faculdade**, com o objetivo de colocar em prática os conhecimentos adquiridos durante os estudos de desenvolvimento web.

A proposta da atividade foi desenvolver uma página pessoal utilizando tecnologias fundamentais do Front-End, trabalhando conceitos de **HTML5, CSS3 e JavaScript**.

Durante o desenvolvimento, foram aplicados conhecimentos relacionados à estruturação de páginas, estilização, organização de conteúdo, responsividade e interatividade.

> 📌 **Importante:** este projeto foi desenvolvido especificamente como uma atividade acadêmica. Ele não representa o portfólio profissional oficial do desenvolvedor.

### 🇺🇸 English

**Site Pessoal** is an **academic project developed as part of a college assignment**, created to put web development concepts learned during the course into practice.

The assignment involved developing a personal website using fundamental Front-End technologies, with a focus on **HTML5, CSS3 and JavaScript**.

The project applies concepts related to page structure, styling, content organization, responsiveness and interactivity.

> 📌 **Important:** this project was specifically developed as an academic assignment. It is not the developer's official professional portfolio.

---

## 🎯 Objetivo da atividade

### 🇧🇷

O objetivo principal deste trabalho foi desenvolver uma página pessoal aplicando, na prática, conceitos fundamentais de desenvolvimento Front-End.

A atividade permitiu trabalhar:

* Estruturação de páginas com HTML5
* Estilização com CSS3
* Responsividade
* Organização de conteúdo
* Interatividade com JavaScript
* Navegação entre seções
* Animações e transições
* Experiência do usuário

Além do resultado visual, o projeto teve como foco principal o **aprendizado e a aplicação prática dos conteúdos estudados em sala de aula**.

### 🇺🇸

The main objective of this assignment was to develop a personal webpage while applying fundamental Front-End development concepts in practice.

The activity covered:

* HTML5 page structure
* CSS3 styling
* Responsive design
* Content organization
* JavaScript interactivity
* Section navigation
* Animations and transitions
* User experience

The main focus of the project was **learning and applying concepts studied during the course**.
